01适用范围与开发者

本政策适用于「元气指数」（英文名称 VitaGauge，以下称“本应用”）及本隐私政策网站。开发者通过本页列出的邮箱提供隐私与用户支持。本应用不要求注册开发者账户，不运营接收健康问答流量的 AI 中转服务器。

02读取和使用哪些信息

Apple 健康数据：只有在您通过系统授权后，本应用才读取步数、步行与跑步距离、活动能量、心率、静息心率、血氧饱和度、睡眠、体重、体能训练、心率变异性、呼吸频率、心肺适能、体脂率、收缩压、舒张压和体温记录，用于本机摘要、趋势和目标回顾。本应用只读取，不向 HealthKit 写入健康样本。原始记录仍由 Apple 健康管理。

您主动提供的内容：包括聊天问题、健康目标及备注、可选昵称、性别和头像，以及您自行配置的 AI 接口地址、模型和 API Key。头像只用于本机展示，不附带到 AI 请求。

语音输入：麦克风与语音权限仅用于您主动开启的语音转文字。识别只在支持的设备和语言上于设备端执行，不回退到云端识别；识别出的文字在您发送后按聊天规则处理。

03什么时候发送到第三方 AI

您主动发送问题、配置自己的 AI 服务并单独同意向该接收方发送数据后，当前问题与有长度限制的近期对话才会通过 HTTPS 从设备直接发送到您配置的接口；您的 API Key 用于该接口认证。

新附带的健康信息按问题选择，通常为最近 7 天，涉及月度趋势时最多为最近 30 天；明确提及的历史日期可能额外附带该日期的选定指标汇总。只有问题涉及目标或个人资料时才会附带相应文本。普通问候和应用使用问题不默认附带新的健康汇总。

本地助理沿用您已授予的系统健康权限，不在每次提问时重复请求授权。您可以在助理页查看数据使用范围。首次向所配置的第三方 AI 发送前，会单独征求同意；同意保存在本机，后续发送至同一接收方时不再重复询问，您可在设置中撤回。近期消息及其中已经包含的健康信息仍可能随在线问题发送。如需移除这些信息，请先清空对话。逐分钟原始样本、头像和模型内部推理不会被作为附件发送。

更换接收地址后需要重新同意；更换地址或协议需要重新输入密钥。撤回同意会停止当前请求并阻止新的发送，但已经到达接收方的数据不能通过取消请求收回。

本地查询和内置资料在设备上处理，不发送模型请求。在线模型仅选择内置健康建议。Pro 内购由 Apple 处理，App 依据 StoreKit 验证交易判断权益；开发者不会收到银行卡资料。

04第三方的处理与数据用途

开发者不出售健康信息，不使用健康数据投放广告，也不在应用中加入广告追踪或第三方行为分析 SDK。数据用于您请求的健康展示、目标管理和问答功能。

您选择的 AI 服务商独立处理收到的信息，其保存期限、模型训练使用、处理地区、费用和删除方式以该服务商的条款及您的账户设置为准，可能涉及您所在地区之外的处理。发送前请查看所选服务商的隐私政策；如不同意，可不启用 AI 功能或撤回同意。本政策不代表对任意自定义接口作出隐私保证。

05本地存储、保留与保护

健康原始样本不作为独立数据库批量复制到应用中。目标、刷新日志、个人资料、头像、AI 接口元数据和聊天记录保存在设备的应用存储中；这些敏感文件使用 iOS 文件保护，并被排除在系统备份之外。聊天记录可能包含问题、回复和其中的健康信息。

会话在内存与磁盘共用有界窗口：最近最多 100 条消息，正文合计最多 200,000 个 UTF-8 字节，单条最多 24,000 个字符；达到任一限制时可能更早移除旧消息。模型推理不持久化。您主动选择恢复损坏资料时，损坏原件会先作为受保护的本地副本保留。

API Key 保存在解锁后可用、仅当前设备的 iOS Keychain 中，与接收地址和协议绑定，不同步到 iCloud Keychain。它不会嵌入 App 安装包、写入日志或上传到开发者服务器。为认证请求，Key 会发送给您配置的 AI 接口。

应用进入后台时会遮盖任务切换器中的敏感界面，并取消 AI、语音和待完成的健康查询。上述措施降低风险，但任何存储和传输都不能保证绝对安全。

06您的选择、撤回与删除

您可在 Apple 健康或 iOS 的健康隐私设置中调整读取权限，在本应用设置中撤回第三方 AI 同意或清除 AI 配置与密钥，在助理页清空本地聊天，并删除目标或修改个人资料。健康摘要与目标等本机功能不要求启用第三方 AI。

卸载应用会移除其应用沙盒文件；请在卸载前使用“清除 AI 配置”删除 Keychain 中的密钥，不要将卸载视为密钥一定被删除的保证。如密钥需要立即失效，请同时在 AI 服务商账户中撤销或轮换。删除本地记录不会删除 Apple 健康中的原始数据，也不会自动删除服务商已经收到的数据。

本应用没有开发者账户，也不提供独立健康数据导出功能。原始健康数据导出请使用 Apple 健康；第三方 AI 访问、删除等请求请联系您选择的服务商。就开发者收到的支持邮件等信息，可通过本页邮箱提出查询、更正或删除请求。

07访问本网站与联系支持

本网站由 GitHub Pages 托管，无登录、表单、分析脚本或外部字体。页面本身不要求您提供健康信息或 API Key。GitHub 可能处理 IP 地址、浏览器信息和访问日志等服务运行数据，详情见 GitHub 隐私声明。

当您主动通过电子邮件联系开发者时，开发者会收到您的邮箱、邮件内容及附件，用于回应问题和处理请求。请勿发送 API Key 或不必要的健康资料；支持信息仅在处理请求及适用的保留义务所需范围内保留。

08儿童隐私与健康提示

本应用不面向 13 岁以下儿童。若您认为儿童向开发者提供了个人信息，请通过邮箱联系以便处理。

本应用提供日常健康信息和 AI 参考内容，不是医疗器械，也不替代医生的诊断、处方或治疗。遇到急症请联系当地急救服务。

09政策更新

本政策自 2026 年 9 月 12 日起生效。后续更新会在本页面标明日期；重大变更会通过应用或 App Store 更新说明告知。新增需要同意的数据处理会按适用要求另行征求同意，不以继续使用替代必要的明确同意。
