常见问题

第一次使用，怎么连接健康数据？

打开 App 后点击“连接 Apple 健康”，在系统页面选择允许读取的类型。也可以稍后到“设置 → 健康数据与权限”继续。App 只读，不修改 Apple 健康中的记录。

为什么步数、睡眠或其他指标没有数值？

先在 Apple 健康中确认对应日期已有记录，再检查本 App 的读取权限并刷新摘要。部分指标依赖 Apple Watch、兼容设备或其他 App。空白不等于零，也无法仅凭空结果判断是否拒绝了读取权限。

没有 API Key 能用什么？

可用摘要、7 天趋势、基础本地查询、一般生活习惯资料和 1 个目标。比如“今天走了多少步”“最近七天每天步数”“如何增加日常活动”。本地无需网络或模型下载。Pro 的本地高级统计也不需要 API。

本地助理为何要求我说明日期？

“昨晚”“上周”或含糊的日期无法保证和当前自然日汇总一致。请改用“昨天”“最近7天”或明确日期，例如 2026-09-01。缺失、异常、重复记录不会编造成答案。

Pro 是订阅吗？

不是。Pro 是一次性买断，首发中国区 ¥38，实际金额以 Apple 购买页为准。没有每月或每年自动扣费。在线服务商使用你的 Key，可能另行收取模型费用。

换手机后怎么恢复？

使用原购买 Apple 账户，在“设置 → 元气指数 Pro → 恢复购买”重查权益。恢复内购不会恢复本机聊天、目标或 API Key；这些敏感资料不随本 App 备份同步。

已付款但没有解锁怎么办？

先确认 Apple 交易已完成，而不是待批准。连接网络后尝试恢复购买；仍有问题请联系支持并提供不含敏感支付信息的错误提示。退款申请可前往 Apple 的 reportaproblem.apple.com。

怎么连接在线 AI？

在“设置 → 连接在线 AI”选择服务商，按官方教程创建自己的 Key，粘贴后点击“验证并保存”。验证只发送固定测试文字，可能产生服务商费用。1.1.0 中，保存配置后请打开助理右上角“⋯ → 对话模式 → API 对话”；选择“本地对话”即可继续在设备上处理，保存的 Key 不会因此被删除。在线使用需要 Pro，首次发送至该接收方还需单独同意数据使用说明。

语音按钮不能用怎么办？

先确认麦克风和语音识别权限，并检查当前设备、语言是否支持端侧识别。本 App 不回退到云端语音识别；不支持时请使用文字输入。1.1.0 的语音改进：点按开始、再次点按结束，也可按住说话、松手结束，上滑或点“取消”放弃本次录音。转写文字先放进输入框，核对后再点击发送。首次允许权限后可能需要再点一次麦克风。达到 55 秒上限会结束录音并保留已识别文字。若提示输入变化，检查当前麦克风后重试。

怎样清除记录和密钥？

助理菜单可清空对话；目标页可删除目标；“连接在线 AI”页面可清除配置与 Keychain 密钥。请在卸载前先清除 AI 配置。删除本地数据不会删除 Apple 健康原始记录或服务商已收到的数据。

这能判断我是否生病吗？

不能。本 App 不诊断、不推荐用药剂量，也不监控急症。生活习惯资料不能替代个体化诊疗；有症状请联系医生，紧急情况请联系当地急救。

为什么某些页面写着 Pro？

7 天内普通查询免费，最近2天也属于普通查询。指定两天作比较、超过7天的窗口、关联统计及多个目标需要 Pro。未配置商品或价格读取失败时，购买按钮会禁用，可重试或恢复。
